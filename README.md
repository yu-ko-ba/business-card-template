# HTML/CSS Business Card Template
HTMLとCSSを使って、ブラウザ上でデザインし、そのまま印刷所の入稿用PDFとして書き出せる「名刺作成テンプレート」です。
特定の職業やデザインに依存しない、真っ白なベースキャンバスを提供します。
## テンプレートの特徴
 * **1ファイル完結**: 表面と裏面を1つの index.html 内に記述できます。
 * **ガイド表示**: 初期状態で「塗り足し」「仕上がり線」「印字保証範囲」のガイドラインとラベルが表示されており、テキストの配置ミスを防ぎます。
 * **自動PDF最適化**: 印刷（PDF出力）時にはガイドラインが自動で非表示になるため、出力前にコードを書き換える手間はありません。正確なサイズ（97mm x 61mm）で裏表が改ページされて出力されます。
## 🤖 Android端末とAIで完結！モダンな名刺作成ワークフロー
PCを開かなくても、Androidスマートフォン（またはタブレット）上のAIアプリとTermux環境を組み合わせることで、「AIへのデザイン発注」から「入稿用PDFの生成」までをすべて端末内で完結させることができます。（※ Termuxアプリを使用するため、iOS環境では実行できません）
ペイントソフトの操作を覚える手間を省き、HTMLとCSSでデザインを構築することで、AIによる部分的な変更や微調整に強く柔軟に対応できるのがこのワークフローのアドバンテージです。
### Step 1: Gemini (AI) にデザインを作ってもらう
スマホ版のAIチャットアプリはファイルの添付に対応していない場合があるため、ソースコードを直接プロンプトに貼り付けて指示を出します。
 1. 以下のURLにアクセスし、テンプレートのHTMLコードをすべてコピーします。
   https://github.com/yuyuyuyuyu-dev/business-card-template/blob/main/index.html
 2. Android端末の **Gemini アプリ**（またはWeb版）を開きます。
 3. AIに対して以下のように指示を出します。
   > 「以下のHTMLコードは名刺のベーステンプレートです。これを構造を維持したままベースにして、私の名刺をデザインし、1つのHTMLファイルとして出力してください。肩書は〇〇、名前は〇〇です。全体的にモダンでミニマルなデザインにしてください。
   > [ここにコピーしたHTMLコードを貼り付け]」
   > 
 4. AIが出力したHTMLコードを確認します。気に入るまで対話形式でデザインをブラッシュアップしてください。
 5. 完成したコードをコピーし、Android端末の **「ダウンロード」フォルダ** 内に index.html という名前で保存します。
### Step 2: Termux で HTML を PDF に変換する
作成したHTMLファイルを高解像度なPDFデータに変換するために、Androidのローカルターミナル環境である Termux と、専用ツール @yuyuyuyuyu-dev/html2pdf を使用します。難しい操作は不要で、以下のコマンドをコピー＆ペーストするだけで完了します。
**1. Termuxの準備（初回のみ）:**
Termuxアプリを開き、ストレージ（ダウンロードフォルダ等）へのアクセス許可と、必要なパッケージのインストールを行います。以下のコマンドを順番にコピペして実行（Enter）してください。
```bash
termux-setup-storage
pkg install -y x11-repo
pkg install -y nodejs chromium

```
**2. PDFへの変換実行:**
以下のコマンドをコピーして実行すると、ダウンロードフォルダにある index.html を読み込み、同じ場所に output.pdf として書き出します。
```bash
npx @yuyuyuyuyu-dev/html2pdf --chromium-path "$(type -p chromium-browser)" --src ~/storage/downloads/index.html --dest ~/storage/downloads/output.pdf

```
これで、端末の「ダウンロード」フォルダ内に、印刷所へそのまま入稿できる output.pdf （2ページ構成）が生成されます！
## 💻 PC環境でのワークフロー
PCをお使いの場合は、ブラウザの印刷機能を使って簡単にPDF化できるほか、より便利なAI環境を活用できる可能性があります。
### 💡 【Tips】Antigravity を活用したデザイン
PC環境でAIを用いて名刺を作成する場合、Googleの **Antigravity** のような、実行環境とプレビュー画面が統合されたAIツールの活用が効果的かもしれません。
通常のチャットベースのAIでは、レンダリング結果を伝えるためにプレビュー画面のスクリーンショットを添付する手間が発生しますが、Antigravityにはプレビュー環境が統合されているようなので、シームレスに変更と確認ができるような気がしています。
### ブラウザ（Google Chrome等）でPDFとして書き出す方法
手動でPDF化する場合は以下の手順で行います。
 1. 作成した index.html をブラウザ（Google Chrome推奨）で開きます。
 2. Ctrl + P (Macの場合は Cmd + P) で印刷ダイアログを開きます。
 3. 以下の設定を行います：
   * **送信先**: 「PDF に保存」
   * **ページ**: すべて
   * **用紙サイズ**: デフォルト または カスタム（CSSの @page 指定が優先されるため基本は変更不要です）
   * **余白**: **「なし」** （※必須設定）
   * **オプション**: **「背景のグラフィック」にチェックを入れる** （※必須設定。チェックがないと背景色が出力されません）
 4. 「保存」をクリックし、PDFファイルを出力します。
